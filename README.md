# physics
практика тема 1.1
информационная система по школьному предмету “Физика”. Система включает в себя такие темы, как:

•	“Тепловое движение. Температура”

•	“Внутренняя энергия”

•	“Способы изменения внутренней энергии тела”

темы предоставлены в виде таблицы, архитектура системы построена с возможностью расширения списка тем и заполнения содержимым. Так же в системе присуствуют вспомогательные функции:

•	Перевод единиц силы тока в амперы (кА, мА, мкА). Например:

o	1 кА = 1000 А

o	1 мА = 0,001 А

o	1 мкА = 0,000001 А

•	Калькулятор по закону Ома:

o	Нахождение I при известных U и R

o	Нахождение U при известных I и R

o	Нахождение R при известных U и I

Всплывает сообщение при вводе значений некорректных результатов.
